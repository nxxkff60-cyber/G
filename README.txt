COPOXXX WEBSITE — ALL SOURCE FILES

Files:
- index.html : page content and sections
- style.css  : all colors, layout, responsive design
- script.js  : mobile menu, topic search, current year
- assets/logo.svg : custom COPOXXX logo
- README.txt : these instructions

HOW TO OPEN:
1. Extract the ZIP in the iPhone Files app.
2. Open index.html in a browser if your file app/browser supports local HTML.
3. For a public website, upload every file/folder preserving the same structure to a GitHub repository.

PUBLISH WITH GITHUB PAGES (iPhone):
1. Create a GitHub repository, for example copoxxx-website.
2. Upload index.html, style.css, script.js, and the assets folder (including logo.svg) to the repository root.
3. Commit the files.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a little and open the URL shown in the Pages section.

CUSTOMIZATION:
- Change visible wording in index.html.
- Change colors and layout in style.css.
- Change menu/search behavior in script.js.
- Replace assets/logo.svg with your own SVG logo if you want.

FEATURES:
Responsive dark neon design, COPOXXX branding, Esports/Gaming/Coding/Web Development/AI/Cybersecurity sections,
30-day roadmap, FAQ, mobile menu and topic search.

IMPORTANT:
This is a static educational website. It does not yet include user accounts, a database, live tournament registration,
payments or a real tournament backend. The Google Fonts import is optional; if internet is unavailable, system fonts are used.
